# Pokedux

A simple pokedex built using React and Redux.  
Uses http://pokeapi.co as the API.

https://jmcsweeny.github.io/pokedux/

## Local Development

1. `npm install`
2. `npm start`  
3. Your site will open at `http://localhost:5173/`

## Production Build

1. `npm run build`
2. The bundled files will be in the `dist/` folder

## Preview Production Build

1. `npm run build`
2. `npm run preview`
3. Your site will open at `http://localhost:4173/pokedux/`
